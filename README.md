# Подборка «Вам понравится»

На главной онлайн-кинотеатра она показывает 10 фильмов и сериалов по истории просмотров. Сравниваем ее с популярностью и со списком похожих тайтлов. Своего трафика нет, поэтому считаем офлайн на публичном срезе [KION](https://github.com/irsafilo/KION_DATASET): там записаны длительность и процент досмотра. Постановка и схемы лежат в [дизайн-документе](docs/ml_system_design_doc.md), разбор среза — в [отчете EDA](reports/eda.md). Обучения и API в репозитории пока нет.

## Решение

1. Бейзлайн — тайтлы, которые до отсечки чаще всего досматривали и по проценту, и по длительности. Второй бейзлайн — то же самое внутри возрастной группы и признака «есть дети». Третий — соседи по совместным досмотрам с поправкой на популярность.
2. MVP — двухбашенный ретривер и списочный ранкер. Вектор тайтла собирается из идентификатора, текста и полей каталога, вектор пользователя — трансформером по истории. Отдельное окно валидации выбирает параметры и ранкер до теста. CatBoost на тех же кандидатах остается контролем: если на валидации он сильнее сети, в тест идет он. Если оба проигрывают списку соседей по совместным досмотрам, в тест идет этот список. Уже начатое убираем, когда последняя дата пары раньше отсечки: более раннего начала файл не хранит. Если истории нет, отдаем популярное в той же демографической группе, а если не поднялась модель — общий топ.

## Данные

Csv в git не кладем. Берем русскую выгрузку `data_original.zip` из [репозитория KION](https://github.com/irsafilo/KION_DATASET/raw/f69775be31fa5779907cf0a92ddedb70037fb5ae/data_original.zip). Это анонимная выборка просмотров KION с добавленным шумом: 5 476 251 взаимодействие, 962 179 пользователей, 15 706 тайтлов. В самом файле даты идут с 13 марта по 22 августа 2021. В README датасета конец периода указан как 22 августа 2022, счетчики строк при этом те же. sha256 архива `50fc5b7db78cbda4c3d0ee5bb5bea4c416cff41e8af58aab0b661d0d3e9dfa9b`. Описание полей и сравнение с MovieLens — в README репозитория и в статье [arXiv:2209.00325](https://arxiv.org/abs/2209.00325).

В `interactions.csv` лежат `user_id`, `item_id`, `last_watch_dt`, `total_dur` и `watched_pct`. Дата в строке — последний просмотр пары. В `users.csv` — пол, возрастная и доходная группы, `kids_flg`: есть ли у пользователя дети, а не кто смотрит сейчас. В `items.csv` — тип (фильм или сериал), названия, год, жанры, страны, возрастной рейтинг, студии, актеры, режиссеры, описание и ключевые слова.

Если используем срез в тексте, цитируем Petrov, Safilo, Tikhonovich, Ignatov. MTS Kion Implicit Contextualised Sequential Dataset for Movie Recommendation. RecSys CARS Workshop, 2022.

## Разработка

Python 3.11+. Линтер и форматтер — Ruff, на коммите их запускает pre-commit. Команды — в [CONTRIBUTING.md](CONTRIBUTING.md).

EDA считается отдельно от пакета:

```bash
uv pip install -e ".[eda]"
python notebooks/01_eda.py
```

Нужны распакованные csv в `data/data_original/`. Скрипт заново пишет графики и `reports/eda_summary.json`.
