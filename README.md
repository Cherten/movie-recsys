# Подборка «Вам понравится»

На главной онлайн-кинотеатра она показывает 10 фильмов и сериалов по истории просмотров. Сравниваем ее с популярностью и со списком похожих тайтлов. Своего трафика нет, поэтому считаем офлайн на публичном срезе [KION](https://github.com/irsafilo/KION_DATASET): там записаны длительность и процент досмотра. Постановка и схемы лежат в [дизайн-документе](docs/ml_system_design_doc.md). Обучения и API в репозитории пока нет.

## Решение

1. Бейзлайн — тайтлы, которые до отсечки чаще всего досматривали и по проценту, и по длительности. Второй бейзлайн — то же самое внутри возрастной группы и признака «есть дети». Третий — соседи по совместным досмотрам с поправкой на популярность.
2. MVP — двухбашенный ретривер и списочный ранкер. Вектор тайтла собирается из идентификатора, текста и полей каталога, вектор пользователя — трансформером по истории. CatBoost на тех же кандидатах остается контролем: если на валидации он сильнее сети, в тест идет он. Если оба проигрывают списку соседей по совместным досмотрам, в тест идет этот список. Уже начатое не показываем: «продолжить просмотр» — другая подборка. Если истории нет, отдаем популярное в той же демографической группе, а если не поднялась модель — общий топ.

## Данные

Csv в git не кладем. Берем русскую выгрузку `data_original.zip` из [репозитория KION](https://github.com/irsafilo/KION_DATASET/raw/f69775be31fa5779907cf0a92ddedb70037fb5ae/data_original.zip). Это анонимная выборка просмотров KION с 13 марта 2021 по 22 августа 2022, в нее добавлен шум: 5 476 251 взаимодействие, 962 179 пользователей, 15 706 тайтлов. Описание полей и сравнение с MovieLens — в README репозитория и в статье [arXiv:2209.00325](https://arxiv.org/abs/2209.00325).

В `interactions.csv` лежат `user_id`, `item_id`, `last_watch_dt`, `total_dur` и `watched_pct`. В `users.csv` — пол, возрастная и доходная группы, `kids_flg`. В `items.csv` — тип (фильм или сериал), названия, год, жанры, страны, возрастной рейтинг, студии, актеры, режиссеры, описание и ключевые слова.

Если используем срез в тексте, цитируем Petrov, Safilo, Tikhonovich, Ignatov. MTS Kion Implicit Contextualised Sequential Dataset for Movie Recommendation. RecSys CARS Workshop, 2022.
